## ABSTRACT

Agriculture is the backbone of the Indian economy, and Gujarat is one of India's leading agricultural states. However, farmers often lack access to timely, data-driven decision support for critical farming activities such as crop selection, disease diagnosis, irrigation planning, fertilizer application, and market price analysis. This project presents the design and development of a **Smart Agricultural System** — a web-based, AI-powered decision support platform specifically tailored for Gujarat farmers.

The system is built using **Python** and the **Flask** web framework and integrates multiple intelligent modules into a unified, user-friendly interface. The **Crop Recommendation Module** utilizes a trained **Random Forest** classifier along with a rule-based scoring engine to suggest the most suitable crops based on soil parameters (Nitrogen, Phosphorus, Potassium, pH, organic carbon, soil texture), season, water availability, and irrigation type. The **Plant Disease Detection Module** employs a **MobileNetV2 Convolutional Neural Network (CNN)** to analyze leaf images uploaded by farmers and identify diseases with confidence scores along with treatment and prevention advice.

The **Smart Irrigation Module** implements a deterministic, multi-rule decision engine that calculates precise water requirements based on soil moisture levels, crop growth stage, weather conditions, rainfall probability, soil type, and irrigation method efficiency. The **Weather Advisory Module** fetches real-time weather data from the **OpenWeatherMap API** and generates bilingual (English and Gujarati) advisories for irrigation scheduling and pest risk assessment. The **Market Price Tracker** integrates with the **Agmarknet (data.gov.in) API** to provide live Gujarat mandi prices with trend analysis and AI-based sell/wait recommendations. Additionally, the system supports **WhatsApp alerts** via the Meta Cloud API and **Email alerts** via SMTP for automated farmer notifications.

The system is deployed locally as a Flask web application and is accessible through a standard web browser, making it accessible to farmers with basic smartphone or computer literacy. All data is stored using JSON files, eliminating the need for a database server.

**Keywords:** Smart Agriculture, Crop Recommendation, Plant Disease Detection, Smart Irrigation, Flask, Machine Learning, Random Forest, MobileNetV2, Gujarat Farming, Weather Advisory
